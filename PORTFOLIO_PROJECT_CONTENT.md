### Challenges Faced
```
1. Performance Optimization: Initially faced slow load times due to Render.com cold starts. Solved by implementing a hybrid caching strategy that pre-fetches data at build time and caches in localStorage for instant repeat visits.

2. CORS Configuration: Encountered cross-origin issues when frontend and API were deployed to different subdomains. Resolved by properly configuring CORS headers with specific allowed origins and methods.

3. Static Site Generation with Dynamic Content: Needed the best of both worlds - static site speed with dynamic content updates. Implemented a solution using pre-built static pages with client-side data freshness checks.

4. Matrix Animation Performance: The canvas-based animation was causing performance issues on mobile. Optimized by reducing particle count, implementing requestAnimationFrame throttling, and adding visibility checks.

5. Multi-subdomain Deployment: Managing nginx configurations for main site, admin panel, and API on a single VPS while keeping an existing site running. Carefully configured separate nginx server blocks and managed SSL certificates.
```
