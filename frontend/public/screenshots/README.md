## Recommended Screenshot Size
- **Dimensions**: 1200x800 pixels (3:2 aspect ratio)
- **Format**: PNG or WebP
- **Quality**: High quality, clear and professional

## Placeholder Display
Until you add actual screenshots, the portfolio will display placeholder boxes with:
- An image icon
- Text "Screenshot Placeholder"
- The expected filename path

## Adding Screenshots
1. Capture screenshots of your projects
2. Resize them to recommended dimensions
3. Save with the exact filenames listed above
4. Place in `public/screenshots/` directory
5. Clear browser cache and reload to see updated images
